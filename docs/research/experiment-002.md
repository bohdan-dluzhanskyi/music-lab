# Experiment 002 · Angular Sequences

**Status** Historical generation reported. Listening ratings unconfirmed.

## Objective and supplied parameters

Investigate how angular step affects musical sequences.

| Parameter | Value |
| --- | --- |
| Notes per sequence | 16 |
| Tempo | 89 BPM |
| Frequency range | 220–440 Hz, octave-folded |
| Harmonics | Four |
| Accompaniment | None |

## Angles explored

- 30°
- 60°
- 90°
- 120°
- 137.507764° (golden angle)
- 180°
- 210°
- 249.927089° (note-clock representation of the golden-ratio frequency interval)

The golden angle is the smaller golden division of a turn. The interval angle is a
logarithmic mapping of a frequency ratio. See [scientific foundations](../scientific-foundations.md).
